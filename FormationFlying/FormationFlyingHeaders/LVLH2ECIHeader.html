LVLH2ECI:

Path: FormationFlying/Transformation

% Given the reference state in ECI, converts an LVLH frame state to ECI.

--------------------------------------------------------------------------
   Form:
   x1 = LVLH2ECI( x0, xL )
--------------------------------------------------------------------------

   ------
   Inputs
   ------
   x0              (6,1) [r;v] ECI frame (reference)
   xL              (6,n) [r;v] LVLH frame

   -------
   Outputs
   -------
   x1              (6,n) [r; v] ECI frame

--------------------------------------------------------------------------
