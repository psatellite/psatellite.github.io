CollisionSimStruct:

Path: FormationFlying/Initialize

 
% ProjCircSimStruct with a new command list to run collision survey.
   
   Since version 7.
--------------------------------------------------------------------------
   Form:
   sim = CollisionDetectSimStruct( el, nOrbits, nSC, jD, ideal );
--------------------------------------------------------------------------

   ------
   Inputs
   ------
   fScale       (1)    Scale factor for initial drift. If not input defaults 
                       to zero. 1/100 causes a collision to be detected.


   -------
   Outputs
   -------
   sim          (.)    Simulation data structure, input to DFFSimulation

--------------------------------------------------------------------------
