 post-simulation message analysis for DFF
% Post-simulation message analysis for DFF.

   Since version 7.
--------------------------------------------------------------------------
   Form:
   MessageAnalysis( msg )
--------------------------------------------------------------------------

   ------
   Inputs
   ------
   msg          (.)    Array of message data structures transmitted between
                       spacecraft over the ISL. After a simulation has been run
                       using the DFFSimulation function, obtain the messages with:
                          msg = DFFISLManagement('get messages');

   -------
   Outputs
   -------
   none

--------------------------------------------------------------------------
