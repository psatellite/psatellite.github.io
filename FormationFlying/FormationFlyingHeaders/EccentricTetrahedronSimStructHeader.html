EccentricTetrahedronSimStruct:

Path: FormationFlying/Initialize

% Eccentric tetrahedron simulation data structure.
 Initialize a DFF simulation data structure for a 4 spacecraft tetrahedron
 geometry in an eccentric reference orbit.
--------------------------------------------------------------------------
   Form:
   sim = EccentricTetrahedronSimStruct
--------------------------------------------------------------------------

   ------
   Inputs
   ------
   apg          (1)     Apogee of reference orbit    [km]
   prg          (1)     Perigee of reference orbit   [km]

   -------
   Outputs
   -------
   sim          (.)    Simulation data structure, input to DFFSimulation

--------------------------------------------------------------------------
