% Computes the value of the cosine function.
   Given the argument in degrees.

   Since version 1.
--------------------------------------------------------------------------
   Form:
   z = CosX( x )
--------------------------------------------------------------------------

   ------
   Inputs
   ------
   x           Angle (deg)

   -------
   Outputs
   -------
   z           Cos(x)

--------------------------------------------------------------------------
