% Plots planet alignments fur successive synodic periods.
 Uses Planets for ephemerides.

 Type PlanetAlignments for an Earth/Mars demo.
--------------------------------------------------------------------------
   Form:
   PlanetAlignments( planet1, planet2, jD )
--------------------------------------------------------------------------

   ------
   Inputs
   ------
   planet1 (1,:) Planet 1 name
   planet2 (1,:) Planet 2 name
   jD      (1,1) Julian date

   -------
   Outputs
   -------
   None
