GroupVariables:

Path: Plotting/GUI

% This function creates an interface for grouping variables
     used by the Plotting Tool.
--------------------------------------------------------------------------
   Form:
   x = GroupVariables( action, modifier  )
--------------------------------------------------------------------------

   ------
   Inputs
   ------
   action          (1,:)   Action to be taken by the gui (used mostly
                           for callbacks)
   modifier        (1,:)   Modifier to the action

   -------
   Outputs
   -------
   x

--------------------------------------------------------------------------
