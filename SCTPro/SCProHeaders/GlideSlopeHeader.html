GlideSlope:

Path: SCPro/ProTools

% Compute the glide slope angle.
------------------------------------------------------------------------
   Form:
   gS = GlideSlope( uGS, rTarget, x, rPlanet )
------------------------------------------------------------------------

   ------
   Inputs
   ------
   uGS     (3,1) Glide slope reference
   rTarget (3,1) Target vector
   x       (3,:) Trajectory
   rPlanet	(1,1) Radius of the target planet

   -------
   Outputs
   -------
   gS      (1,:) Glide slope angle (deg)

------------------------------------------------------------------------
