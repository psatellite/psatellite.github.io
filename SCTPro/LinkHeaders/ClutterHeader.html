Path: Link/Radar

% Compute clutter for land or sea.
--------------------------------------------------------------------------
   Form:
   sigma0 = Clutter( type, f, thetaG, sS )
--------------------------------------------------------------------------

   ------
   Inputs
   ------
   type          (1,:)    Type 'sea', 'desert', 'farmland', 'wooded hills',
                          'mountains'
   f             (1,1)    Frequency (GHz)
   thetaG        (1,1)    Grazing angle (rad)
   sS            (1,1)    Sea state (0-8);

   -------
   Outputs
   -------
   sigma0        (1,:)    Clutter coefficient

--------------------------------------------------------------------------
