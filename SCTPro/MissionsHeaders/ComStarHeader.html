ComStar:

Path: Missions/Comsat

% The ComStar satellite properties database GUI. 
 If q = 'Catalog' it will list a catalog of available data. 
 Inputs are case sensitive.
--------------------------------------------------------------------------
   Form:
   [x, u] = ComStar( q, gUICode )
--------------------------------------------------------------------------

   ------
   Inputs
   ------
   q             (1,:)    String describing the type of data

   -------
   Outputs
   -------
   x             (:,:)    The properties
   u             (1,:)    Units

--------------------------------------------------------------------------
