TransferOrbit:

Path: Missions/Comsat

% Simulates transfer orbit

--------------------------------------------------------------------------
   Form:
   TransferOrbit( event, mET, a, eventName, dateStart, database )
--------------------------------------------------------------------------

   ------
   Inputs
   ------
   event           (:,:) Event to be simulated
   mET             (1,1) Mission elapsed time [h,m,s]
   a               (1,:) Event data
   eventName       (1,:) Name of event
   dateStart       (1,6) [year month day hour minute second]
   database        (1,:) Database name
   inertiaName     (1,:) Name of the starting inertia
   units           (2,3) ['mks'|'lbf'|'sft';'deg'|'rad';'rpm'|'rps']

--------------------------------------------------------------------------
