% Generate a response to an initial condition vector.
--------------------------------------------------------------------------
   Form:
   [y, x] = IC( g, x, dT, nSim )
--------------------------------------------------------------------------

   ------
   Inputs
   ------
   g                      State space system of type statespace
   x                      Initial state vector
   dT                     Time step
   nSim                   Number of steps

   -------
   Outputs
   -------
   y                      Response
   x                      State response

--------------------------------------------------------------------------
