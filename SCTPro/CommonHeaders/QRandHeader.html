QRand:

Path: Common/Quaternion

% Generates random quaternions. 
 The first element is always positive.
--------------------------------------------------------------------------
   Form:
   q = QRand(n)
--------------------------------------------------------------------------

   ------
   Inputs
   ------
   n	(1,1)   Number of quaternions

   -------
   Outputs
   -------
   q	(4,n)   Random quaternions.    

--------------------------------------------------------------------------
