mtimes:

Path: Common/@transmat

--------------------------------------------------------------------------
   Multiplies an object of type quaternion times a quaternion or a vector.
--------------------------------------------------------------------------
   Form:
   c = mtimes( a, b )
--------------------------------------------------------------------------

   ------
   Inputs
   ------
   a           (:)   Object of type transmat
   b           (:)   Object of class transmat, quaternion or a vector

   -------
   Outputs
   -------
   c           (:)  Object of class transmat

--------------------------------------------------------------------------
