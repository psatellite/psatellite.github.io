PrintEigenvalues:

Path: Common/Control

% Print eigenvalues to the command window.

   Type PrintEigenvalues for a demo.
--------------------------------------------------------------------------
   Form:
   PrintEigenvalues( g, f, t )
--------------------------------------------------------------------------

   ------
   Inputs
   ------
   g               (:)      State space system or a matrix
   f               (1,:)    Format, ie:  '%7.3f'
   t               (1,:)    Title

   -------
   Outputs
   -------
   f               (:)      Gain matrix

--------------------------------------------------------------------------
