Path: Common/@statespace

% Get the state space matrices
--------------------------------------------------------------------------
   Form:
   [a, b, c, d] = getabcd( x )
--------------------------------------------------------------------------

   ------
   Inputs
   ------
   x           (:)   Object of class statespace

   -------
   Outputs
   -------
   a           (:)   State matrix
   b           (:)   Input matrix
   c           (:)   Output matrix
   d           (:)   Feedthrough matrix

--------------------------------------------------------------------------
