WireFRB:

Path: SC/Dynamics

% Spacecraft with multiple wires

   Since version 2.
--------------------------------------------------------------------------
   Form:
   xDot = WireFRB( x, t, s, mu, torque, force )
--------------------------------------------------------------------------

   ------
   Inputs
   ------
   x              (m,1)     The state vector
                            [x;v;q;w;xWire;vWire]
   t                        Time
   s              (:)       Wire data structure
   mu             (1,1)     Gravitational parameter

   -------
   Outputs
   -------
   xDot         (m,1)       The derivative of the state vector

--------------------------------------------------------------------------
