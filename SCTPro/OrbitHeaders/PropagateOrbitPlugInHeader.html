--------------------------------------------------------------------------

--------------------------------------------------------------------------

   ------
   Inputs
   ------
   action      (1,:)  Action 'initialize', 'update'
   modifier    (1,:)  Modifier to the action or data structure if intialization

   position    (1,4)  [left bottom width height]

   Outputs

   x           (1,1)  The tag if action is 'initialize'
